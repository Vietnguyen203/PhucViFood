# PHÚC VỊ FOODS — Vector logo exports

All variants use a `1024 × 1024` viewBox and contain only editable SVG vector shapes. Lettering has been converted to individual outline paths; no `<text>` or raster `<image>` elements are present.

## Variants

- `phuc-vi-gold-transparent.svg` — gold gradient on a fully transparent background
- `phuc-vi-gold-dark-red.svg` — gold gradient on `#4A0A0D`
- `phuc-vi-red-white.svg` — one-color `#9B1C22` on white

## Named layers

1. `Background` — present only in the dark-red and white variants
2. `Chef-hat icon`
3. `Wordmark — PHÚC VỊ (outlined)`
4. `FOODS (outlined)`
5. `Tagline — Hương vị của hạnh phúc (outlined)`

The SVG groups use Inkscape layer metadata (`inkscape:groupmode="layer"` and `inkscape:label`) and remain individually selectable in compatible vector editors.

## Color specification

The gold variants use one shared linear gradient:

- `#E3B04B`
- `#D9A441`
- `#B8862B`

The transparent variant contains no background shape.
